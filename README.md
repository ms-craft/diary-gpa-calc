# Средний балл

Chrome/Edge-расширение, которое собирает оценки из электронного дневника и строит наглядный отчёт: средний балл по предметам и четвертям, распределение оценок, сводка и карточки с детализацией.

## Возможности

- Средний балл по каждому предмету и по всем предметам
- Средний балл по четвертям
- Графики: средний по предметам и распределение оценок
- Лучший и слабейший предмет
- Карточки с детализацией: дата, урок, оценка
- Экспорт в CSV (для Excel) и сохранение в PDF
- Использует уже открытую авторизованную вкладку — отдельный вход не нужен
- Минимальные разрешения: только `activeTab` и `scripting`

## Установка (Chrome / Edge)

1. Склонируй репозиторий или скачай ZIP и распакуй в постоянную папку.
2. Открой страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение**.
5. Выбери папку с `manifest.json`.
6. Открой электронный дневник, войди в аккаунт и перейди на страницу ученика.
7. Нажми на значок расширения → **Рассчитать оценки**.
8. Отчёт откроется в новой вкладке.

> Если браузер блокирует всплывающую вкладку — разреши pop-up для сайта и запусти ещё раз.

## Структура проекта

```
diary-gpa-calc/
├── manifest.json   # конфигурация расширения (MV3)
├── popup.html      # окно расширения
├── popup.js        # запуск скрипта на активной вкладке
├── content.js      # сбор оценок и построение отчёта
└── README.md
```

## Технические детали

- **Version:** 1.1.0
- **Разрешения:** `activeTab`, `scripting`
- **Браузеры:** Google Chrome, Microsoft Edge (и другие Chromium-браузеры)
- Отчёт строится локально в новой вкладке; данные не отправляются на сторонние серверы

## Важно

Расширение рассчитано на ту же структуру сайта и те же URL дневника, что и исходный скрипт. Если разметка дневника изменится, сбор оценок может потребовать правки `content.js`.
