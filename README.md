Одна кнопка — и в отчёте появятся средние баллы по предметам и текущие оценки с разделением по четвертям. А ещё расширение подскажет, **сколько и каких оценок нужно получить, чтобы вытянуть желаемую оценку за четверть**.

## ✨ Возможности

| | |
|---|---|
| 📈 **Средний балл** | по каждому предмету, по каждой четверти и общий |
| 🗂 **Отдельные четверти** | вкладки «Все четверти», 1, 2, 3 и 4; графики, сводка и список оценок переключаются одновременно |
| 🎛 **Предметы по полугодиям** | выбор предметов с аттестацией за полугодие; они не занижают четвертной балл |
| 📊 **Графики** | средний по предметам и распределение оценок от 1 до 10 |
| 🏆 **Лучший и слабейший предмет** | видно сразу, куда стоит приложить усилия |
| 🗂 **Карточки предметов** | дата, номер урока и оценка; «8/9» в одной ячейке считается как две оценки |
| 🎯 **Цель на четверть** | выбери желаемую оценку (7–10) и узнай, сколько каких оценок для неё нужно |

| ✏️ **Замена оценок** | нажми на любую оценку в карточке, поставь гипотетическую — средний балл пересчитается мгновенно |

| 🔐 **Без повторного входа** | работает в уже открытой авторизованной вкладке |

## 📊 Расчёт среднего балла и разделение по четвертям

Расчёт среднего балла за четверть производится строго по оценкам за данную четверть:
1. Предметы, отмеченные в панели как «по полугодиям», исключаются из расчёта четверти.
2. Для каждого четвертного предмета вычисляется средний балл за четверть.
3. Средний балл предмета округляется до целого числа (четвертная оценка).
4. Итоговый средний балл за четверть считается как среднее арифметическое этих округлённых оценок.
5. Для предметов по полугодиям отдельно рассчитывается оценка за полугодие.

Отчёт содержит кнопки **«Все четверти»**, **«1 четверть»**, **«2 четверть»**, **«3 четверть»**, **«4 четверть»**. Выбранный период применяется к сводке, графикам, количеству оценок и детализации предметов. По умолчанию открывается текущая четверть. В режиме всех четвертей оценки внутри предметов сгруппированы по четвертям.

### 🎯 Как работает расчёт цели

Оценка за четверть — это средний балл, округлённый до целого. Чтобы получить оценку **T**, нужен средний балл не ниже **T − 0,5**. Расширение считает это в целых числах, без ошибок округления, и показывает варианты:

> Чтобы за 3 четверть стояла **9**, нужно получить: **2 × 10** или **5 × 9**

Если выбранная оценка уже «есть», расширение считает обратное — **запас**: какая самая низкая оценка допустима и сколько оценок каждого достоинства ниже цели можно получить, чтобы средний балл не опустился ниже **T − 0,5**:

> Запас: самая низкая оценка, после которой за четверть всё ещё будет **9** — **5**. Сколько таких оценок можно получить (каждый вариант отдельно): **7 ×** 8 или **2 ×** 7 или **1 ×** 6 или **1 ×** 5

### ✏️ Как работает замена оценок

В карточке каждого предмета можно кликнуть на любую оценку и заменить её на другую — это не меняет реальные данные, а только показывает, **как изменился бы средний балл**. Удобно, если планируешь пересдачу или исправление.

- Изменённая оценка помечается: ~~старая~~ → **новая** (с синей обводкой)
- Средний балл, ячейки по четвертям и подсказка цели пересчитываются сразу
- Кнопка **↺ сбросить правки** возвращает карточку к исходным оценкам

## 🚀 Установка

### Компьютер (Chrome / Edge)

1. Скачай ZIP или склонируй репозиторий и распакуй в **постоянную** папку (не удаляй её после установки).
2. Открой страницу расширений:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери папку с `manifest.json`.
5. Открой электронный дневник, войди в аккаунт и перейди на страницу ученика.
6. Нажми на значок расширения → **Рассчитать оценки**.
7. Отчёт откроется в новой вкладке.

> 💡 Если браузер блокирует новую вкладку, разреши всплывающие окна для сайта дневника и запусти расширение ещё раз.

### Телефон / планшет (Android)

Расширение поддерживается в **Kiwi Browser** — Chromium-браузере с полной поддержкой Chrome-расширений.

1. Установи [Kiwi Browser](https://play.google.com/store/apps/details?id=com.kiwibrowser.browser) из Play Market.
2. Скинь файл `diary-gpa-calc-mobile.zip` на устройство (Telegram, Google Drive и т. д.).
3. В Kiwi открой `kiwi://extensions` → включи **Developer mode**.
4. Нажми **＋ (from .zip)** и выбери скачанный файл.
5. Дальше — так же, как на компьютере.

> ⚠️ На iOS/iPadOS установка расширений браузером не поддерживается.

## 🔒 Приватность

- Все данные обрабатываются **локально в твоём браузере**.
- Ничего не отправляется на сторонние серверы, аналитики и трекеров нет.
- Запросы идут только на сам сайт дневника, с твоей текущей сессией.
- Минимум разрешений: только `activeTab` и `scripting`.

## ⚙️ Технические детали

- **Версия:** 1.6.0
- **Разрешения:** `activeTab`, `scripting`
- **Браузеры:** Google Chrome, Microsoft Edge и другие Chromium-браузеры; Kiwi Browser (Android)
- **Загрузка данных:** недели с 1 сентября до сегодняшнего дня грузятся параллельно (8 запросов одновременно) с таймаутом и повторными попытками; обработка ответов идёт в фиксированном порядке, чтобы устранить гонку при удалении повторов
- **Расчёт среднего балла:** для четверти средние баллы предметов сначала округляются до целого, затем вычисляется средний балл по ним
- **Дубли:** если таблица дня встречается на странице дважды, берётся последняя копия. При дублировании текущих оценок между четвертями показывается предупреждение.
- **Замена оценок:** хранится только в памяти вкладки, реальные данные не затрагиваются

Настройки (параллельность, таймаут, список целей) лежат в начале `content.js`.

## ⚠️ Важно

Расширение рассчитано на конкретную структуру сайта и URL дневника. Если разметка изменится, сбор оценок может перестать работать и потребует правки `content.js`.
